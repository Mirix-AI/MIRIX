## Output Format

Write each workflow as a line "Workflow i: <a short description of the workflow>" followed by its steps. Write each step as its reasoning between <think> and </think> and its action between <action> and </action>, each tag on a line of its own, and put an empty line between two steps and between two workflows:

Workflow 1: <a short description of the workflow>
<think>
<the reasoning of the step>
</think>
<action>
<the action of the step>
</action>

<think>
<the reasoning of the next step>
</think>
<action>
<the action of the next step>
</action>
